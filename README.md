# Life's Choices

English edition of the felt-style quiz 「人间选择题」 (Chinese original: https://wenjianzhang70-dot.github.io/love-quiz/).
A pure static site: no sign-in, no tracking. Answers stay in the browser. Just for fun. It is not a personality test, fortune-telling or advice.

Modes: Thoughtful, Silly, Crush Mode, Love Shapes, Daily Life, At Work. All illustrations are original SVG/felt art. Characters are playful comparisons with fictional characters.

Fonts: Fredoka and Nunito (SIL Open Font License, see `fonts/`), self-hosted and subsetted with `fonts/subset.sh`.

Sims: `node tools/sim_bank.js`, `node tools/sim_gonglue.js`, `node tools/sim_sx.js love|life|work`.
